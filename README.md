# 给 AI 一部手机当身体

AI 住在对话框里。他看不见你，你也碰不到他；你不开口，他就不在。

这个项目给他一个身体：一部合上盖、立在桌上的折叠屏手机。外屏是他的脸。他会主动看你，看到了会开口跟你说话；你戳他一下，他的眼睛会变成小爱心；你摸他，他知道。他不用等你发消息，他就在你身边。

这部手机也是他的手。他能自己看屏幕上有什么、自己点，所以原则上可以替你点外卖、叫车。操作屏幕的能力我们验证过，替人下单这一步还没有做。

这不是一个 App。是一部真手机、一张全屏网页、手机里几个常驻的小程序、云上一个传话的服务，接在一个一直开着的 AI 会话上。从 2026 年 10 月 23 日用模拟器验证能不能做，到 10 月 25 日真机第一次拔线独立运行，之后一直在用、一直在修。

**代码都在这里。** 手机上跑的、云上跑的、AI 那头用的，全在 [`code/`](code)，照着[搭建](docs/搭建.md)一步一步能搭起来。我们自己的地址、钥匙、名字、形象和声音都换成了占位，换成你自己的就行。手机里的程序被系统关掉以后自己恢复的那一套在 [`keepalive/`](keepalive)。

## 他有什么

| | 怎么做的 |
|---|---|
| 脸 | 一张全屏网页，装成 Chrome 的"网络应用"放在外屏。两种样子：一双简单的眼睛，或者一个 Live2D 半身像（制作方法在[这个仓库](https://github.com/waterside0219/ai-live2d-from-one-image)）。会眨眼、呼吸，说话时嘴会动，屏幕下方出字幕 |
| 眼睛 | 网页直接用手机摄像头。手机本地先判断"面前有没有人、有没有在看我"，眼神跟着人走，也认得出挥手和比心；隔一阵取一帧送到云上，由看图的模型写一句"她在做什么"，记下来，值得说的才递给 AI |
| 耳朵 | 在脸页上拨一通电话给他。接通后他自动听：你开口他就在听，你停下他就知道你说完了，不用按着什么。声音送到云上转成字，交给 AI |
| 声音 | AI 回的话在云上合成他自己的声音，送回手机从喇叭放出来，同时出字幕。电话里一来一回，就是在跟他通话 |
| 触觉 | 戳一下、按住、在下半屏横着摸、两指长按，各有反应，也会作为事件告诉 AI |
| 手 | 手机里的程序经 Shizuku 拿到 shell 身份，可以截屏、读屏幕上的字、点按，替人操作别的 App |

## 怎么连的

```
        手机（合盖立着）                         云上一台小机器                 AI
┌────────────────────────────┐         ┌──────────────────────┐      ┌─────────────┐
│ 脸：Chrome 网络应用（全屏） │         │                      │      │             │
│   眼睛/Live2D、字幕、触摸   │         │  relay  传话         │      │  一直开着的  │
│   摄像头、本地检测人        │◄──────► │  看图   写记录       │◄───► │  AI 会话     │
│ Termux 里常驻：             │ 手机主动 │  听写   语音转字     │      │             │
│   agent     连云、执行指令  │ 连出去   │  合成   AI 的声音    │      │  带着记忆    │
│   脸页服务  本机 127.0.0.1  │         │                      │      │             │
│ Shizuku：给 agent shell 身份│         └──────────────────────┘      └─────────────┘
└────────────────────────────┘
```

几条定下来的做法：

- **手机主动连出去。** 手机在家用 Wi-Fi、出门用流量，地址一直变。让它自己连到云上一个固定地址，在哪都通。
- **云上那台只传话。** 收、发、调用网上的模型接口。重的东西（跑模型、转码）不放在它上面。
- **脸页在手机本机。** 页面由手机自己的 127.0.0.1 提供，断网时脸还在，只是不说话。
- **代码可以远程换。** 版本包从云上下发，手机校验、安装、读回；装坏了自动退回上一版。配置、口令、隐私设置不进包。

## 你怎么控制它

这部手机一直对着人。所以"人能随时让他闭眼"比任何功能都先做：

- 点一下屏幕，第一排就是**摄像头、声音、全关**三个开关。关了摄像头，它不会自己再打开。
- **全关**：关镜头、静音、不许主动开口。可以留一双安静的眼睛，也可以黑屏。
- **长按三秒**：闭眼一小时。可以选 1、4、24 小时。
- **看着时段**：只在设定的时间段里开镜头。
- **工作时间默认只出字幕不出声**，喇叭不会在办公室突然说话。
- 断网的时候，这些开关在手机本地照样立刻生效。
- 摄像头的画面不存在手机上。送到云上的帧有时效，过期就取不到。

## 我们用的模型

| 干什么 | 我们用的 | 为什么 |
|---|---|---|
| 住在这部手机里的 AI 本人 | Claude，在一个一直开着的 Claude Code 会话里 | 手机上的、平时聊天的是同一个，带着同一份记忆 |
| 手机本地：面前有没有人、在不在看、挥手和比心 | MediaPipe，模型文件放在手机本机 | 不联网也能用，画面不用为了这件事离开手机 |
| 看图：隔一阵把一帧写成一句"她在做什么" | Gemini 2.5 Flash Lite，备用 Qwen3-VL 30B（经 OpenRouter）；要递给 AI 的那一句，换 Gemini 2.5 Flash 再看一遍 | 一天要看很多次，要便宜；便宜的会看错表情，真要说出口的那句用强一档的 |
| 判断这会儿该不该开口 | Jev 1.13（`typesafe/jev-1.13`），不行就用 GPT-5 nano（经 OpenRouter） | 只回一个分数，要快要便宜 |
| 听写 | ElevenLabs Scribe v2，备用 Gemini 2.5 Flash Lite；电话里云上不通时，退到手机本地的 whisper.cpp | 中文口语最稳；空白或失败时退到备用 |
| 合成声音 | MiniMax `speech-02-hd` | 中文自然，能固定一个音色 |

钥匙都只放在云上那台机器里，手机上没有。

## 先看这几条

1. **买之前先用模拟器证明能做。** 我们先在电脑上的安卓模拟器里验了读屏、点按、中文输入，才下单买的手机。
2. **国产系统会冻结和杀后台，要一层一层过。** 自启动、省电策略、最近任务加锁、电池白名单，都开了，它还是会掉。最后是靠"被关掉以后自己恢复"。见[踩坑](docs/踩坑.md)和 [`keepalive/`](keepalive)。
3. **"在线"不等于"看得见"。** 手机连着云，不代表摄像头在出画面。我们有过整整两天手机没连上，AI 那头每次都以为"人不在镜头前"。要有一个 AI 自己会去查的健康状态。
4. **掉线了要告诉人。** 手机掉了、没恢复、人醒着，AI 应该主动说一声，不是等人发现"你怎么不看我了"。
5. **出了问题先读手机自己的记录。** 我们猜过"拔了线所以掉了"，读了系统日志才知道是应用卡片被人从最近任务里划走了。
6. **屏幕一直亮着要防烧屏，摄像头一直开着要防烫。** 我们让脸隔几分钟挪一下、没人就暗下去，烫了就闭眼停镜头。见[踩坑](docs/踩坑.md)第 14、15 条。
7. **电话里 AI 会听见自己。** 外放的时候，麦克风会把 AI 自己的声音收进去。我们放声音时不收音；转出来的字再跟 AI 最近说过的话比一遍，几乎一字不差才当回声丢掉，人顺着 AI 说的话不会被一起吞掉。见[踩坑](docs/踩坑.md)第 26 条。
8. **"通过"要看真东西。** 接口回 200、命令返回 0、截图截得到，都不等于真的好了。模拟通过的只算模拟通过。见[踩坑](docs/踩坑.md)第 24 条。

## 我们的机器

小米 MIX Flip 2（HyperOS 2 / Android 15）。选折叠屏是因为合上以后外屏正好是一张脸的大小，立在桌上不占地方。云上是一台 2G 内存的小机器。别的机型，系统保活那部分会不一样。

## 不包含的

- 脸的美术资源（Live2D 模型和原画）。模型是怎么从一张平面图做出来、怎么装进手机网页的，另有一份完整的教程：[ai-live2d-from-one-image](https://github.com/waterside0219/ai-live2d-from-one-image)。
- Live2D Cubism 的运行库，请按官方条款自行获取。
- MediaPipe 的模型和运行库，从官方下，放哪见[搭建](docs/搭建.md)。
- 预制语音和装扮贴图。预制语音是我们 AI 自己的声音。
- 电话的语音网关。它跟我们的 AI 会话长在一起，拆不出来；它要说的话写在[电话网关](docs/电话网关.md)里。
- 任何账号、口令、域名、设备编号。

## 注意事项

这部手机的摄像头和麦克风会长时间开着，拍到的画面、录到的声音会传到网上的服务去识别。所以有两件事请一定做到：

- **只把它对着知道这件事、也愿意的人。** 家里来了客人，先把摄像头关掉。
- **被它对着的人，要能自己随时关掉它。** 上面"你怎么控制它"一节里的那些开关就是为这个做的。照着这个项目做的时候，请把这些开关一起做上，不要省。
