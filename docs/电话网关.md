# 电话网关要说的话

手机上的电话服务（[`code/call-web/server.py`](../code/call-web/server.py)）不直接找 AI，它找一个**语音网关**。网关一头是这通电话，一头是 AI 的会话：把人说的话交给 AI，把 AI 的回话合成声音送回来。

我们的网关跟我们的 AI 会话长在一起，拆不出来，没放进仓库。你要接自己的 AI，照下面做一个就行。所有请求都带 `Authorization: Bearer <设备口令>`（手机上 `device_token_file` 里那一串）。

## 三个地址

| | 干什么 |
|---|---|
| `POST /calls`，body `{"id": "<UUID>", "profile": "<配置里的 profile>"}` | 手机拨出：建一通电话。回 200，body 里 `id` 跟请求的一样 |
| `WS /calls/{id}/stream` | 这通电话的双向通道，下面那些消息都在这里走 |
| `POST /calls/{id}/end`，body `{"state": "ended"}` | 挂断。要能重复调（手机可能会补发） |

AI 打给人的时候反过来：网关先自己建好一通电话，然后经中转让手机响铃：

```json
{"action": "call_incoming", "args": {"id": "网关建好的那个 UUID"}}
```

手机亮屏、震一下、响铃 30 秒。人上划接起来，手机就连这通已有的电话；下划拒接，手机调 `/end`；30 秒没人接，手机留一条"未接来电"。

## 通道里的消息

**手机发给网关的：**

| type | 什么时候 |
|---|---|
| `media_ready` | 手机准备好收声音了（断线重连后也会再发一次） |
| `draft`、`submit` | 人说完一句，转好的字：`{"type":"submit","id":"…","text":"…","manual":true}`。只有声音没认出字的（笑、叹气），text 会是一句提示"对方发出了一点声音，没有识别出文字，请轻轻接一下，不要追问" |
| `played` | 一批声音放完了，带 `generation` |
| `pong` | 回网关的 `ping` |
| `finalize_deferred` | 回网关的 `finalize`，表示这句先不收尾 |

**网关发给手机的：**

| type | 说明 |
|---|---|
| `ready` | 通了 |
| `playback` | 开始一批新的回话，带 `generation`（一个递增的数，换话题就换一个，手机靠它丢掉旧的） |
| `audio` | 一段声音：32kHz、单声道、PCM16LE，base64 放在 `pcm` 里，带 `audio_sequence`（递增）和 `generation`；可以带 `text` 和 `line_id`，字幕就跟着这段声音一起出 |
| `audio_part_end` | 一句合成完了：`{part, generation, audio_sequence, line_id, text}`。**每句合成好就发，别等整段**，第一句才能快 |
| `audio_end` | 这一批全发完了 |
| `line` | 一行文字记录：`{"line": {"id": "…", "role": "assistant" 或 "you", "text": "…"}}`。`role` 是 `assistant` 的，手机会记下来做回声比对 |
| `call` | 状态：`{"state": "ended" / "failed" / "cancelled" / "missed" …}`，前四个手机收到就收线 |
| `error` | `{"message": "…"}`，手机会把 message 显示出来 |
| `ping` | 心跳 |

带 `sequence` 或 `audio_sequence` 的消息，手机按编号去重：断线重连后网关重发的旧消息不会被放两遍。

## 网关这头要注意的

- **别把人的声音当插嘴。** 手机在放 AI 的话时，自己就不收音（半双工），也不理会 `interrupt`。如果网关自己有"听到声音就打断生成"的策略，要关掉：手机这头停了，网关那头已经取消掉的话就找不回来了。
- **掉线了要等。** 手机断线后 90 秒内会一直重连，重连上先发 `media_ready`。网关这 90 秒里别把电话关掉。
- **回声手机会挡一道，网关也可以挡。** 手机外放时，麦克风会听见 AI 自己的声音。手机这头的做法：转出来的字，跟最近 60 秒 AI 说过的每一句比，长短相近（一句是另一句的 0.75 到 1.33 倍）、相似度到 0.9 以上，就当回声丢掉；不到 4 个字的不比。门槛定得这么严，是因为人常常顺着 AI 的话说，比如 AI 说"我也爱你"，人回"我也爱你呀"，这句不能被当成回声吞掉。
