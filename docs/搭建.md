# 照着搭起来

这不是装一个 App。要动手的地方有三处：云上一台小机器、手机、AI 那头。按下面的顺序来，每一步后面写了怎么确认它成了。

代码都在 [`code/`](../code)，每一块是干什么的见 [code/README.md](../code/README.md)。

## 0. 先备齐

- **一部安卓手机。** 我们用的是小米 MIX Flip 2（Android 15）。别的机型也能跑，但第 3 步保活那部分要自己摸。
- **一台电脑，装好 adb。** 第一次起 Shizuku、往手机里拷文件用。
- **云上一台 Linux 小机器。** 2G 内存够，Python 3.11 以上，云上这几个程序只用标准库。
- **一个手机能从外面连到的地址。** 我们用 Cloudflare Tunnel 把一个域名转到这台机器的 127.0.0.1:8832，只放行 `/agent` 这一个路径。用别的隧道或反向代理也行，要求一样：只开放 `/agent`，走 TLS。
- **几把钥匙：** OpenRouter（看图、判断该不该开口、听写的备用）、MiniMax（合成声音，要先在 MiniMax 上做好一个音色拿到 voice_id）、ElevenLabs（听写，可选，没有就全走 OpenRouter）。
- **一个一直开着的 AI 会话，跑在 tmux 里。** 我们用的是 Claude Code。会话要能跑命令（用来调 `phone.py`）。

所有钥匙、口令都放在 `code/.private/` 里，这个目录不进 git。

```
cd code
mkdir -p .private && chmod 700 .private
python3 -c "import secrets; print(secrets.token_urlsafe(32))" > .private/body-device-token
```

`body-device-token` 是手机和中转之间的口令，手机那边的配置里要填同一串。

## 1. 云上：中转

```
echo '你的 MiniMax 钥匙'      > .private/minimax-api-key
echo '你的 OpenRouter 钥匙'   > .private/openrouter-hearing-key
echo '你的 ElevenLabs 钥匙'   > .private/elevenlabs-stt-key      # 可选
chmod 600 .private/*
cp deploy/relay.example.json deploy/relay.json                   # 把 voice_id 改成你的音色
python3 -B server/body_relay.py --config deploy/relay.json
```

常驻：用 [`deploy/body-relay.service`](../code/deploy/body-relay.service)（`systemctl --user`），或者 cron 每分钟拉一次、外面套 `flock -n` 保证只有一个。

隧道只转 `/agent`。Cloudflare Tunnel 的写法：

```yaml
ingress:
  - hostname: relay.你的域名
    path: ^/agent$
    service: http://127.0.0.1:8832
  - service: http_status:404
```

**确认：** `curl -s 127.0.0.1:8832/v1/health` 回 `{"phone_connected": false}`。

## 2. 手机：装东西

**装这几个 App**（Termux 三件套要从同一个地方下，签名要一致，我们用的是 F-Droid/GitHub 版）：Termux、Termux:Boot、Termux:API、Shizuku、Chrome。

**在 Termux 里：**

```
pkg install python python-pillow termux-api
pip install aiohttp          # 只有打电话要用；pip 要编译的话先 pkg install clang
```

**起 Shizuku：** 手机连电脑，在 Shizuku 里按"通过连接电脑启动"的说明跑一条 adb 命令。然后在 Shizuku 里"在终端应用中使用 Shizuku"，把 `rish` 和 `rish_shizuku.dex` 导出来，放到 `~/phone-agent/`。

**拷代码：** 手机上的目录要是这个样子：

```
~/phone-agent/     ← code/phone-agent
~/face/            ← code/face
~/call-web/        ← code/call-web（不打电话可以不放）
```

**填配置：** `cp ~/phone-agent/config.example.json ~/phone-agent/config.json`，改：

- `url`：`wss://relay.你的域名/agent`
- `token`：跟云上 `.private/body-device-token` 同一串
- `apps`：允许 AI 打开的 App，别名对包名。不在这里的 AI 开不了。

然后 `chmod 600 ~/phone-agent/config.json`。

**放看人用的模型（必须）：** 脸页在手机本地用 MediaPipe 看人。从 MediaPipe 官方下：

```
~/face/vendor/vision/vision_bundle.mjs 和 ~/face/vendor/vision/wasm/   ← npm 包 @mediapipe/tasks-vision 里的
~/face/models/face_landmarker.task
~/face/models/gesture_recognizer.task
~/face/vendor/efficientdet_lite0_uint8.task
```

**Live2D（可选）：** 不放就只有眼睛。要放：`~/face/vendor/live2dcubismcore.min.js`（Live2D 官网按条款下载）、`~/face/vendor/cubism-framework.js`（从 CubismWebFramework 编出来），模型放进 `~/face/runtime/`，入口文件名改成 `model.model3.json`。模型怎么从一张图做出来，见 [ai-live2d-from-one-image](https://github.com/waterside0219/ai-live2d-from-one-image)。`face/live2d-v2.js` 里的 `exclusion()` 按部件名找脸的范围（字幕要避开），部件名跟你的模型对不上就改那一行。

**预制语音（可选）：** `~/phone-agent/presets/1.mp3 … N.mp3`，跟 `presets.json` 里的字一一对应（第 1 个字对 1.mp3），最多 10 条。用你的 AI 的声音录好放进去，常用的短回应就不用每次现合成。

**跑起来：**

```
bash ~/phone-agent/termux-boot.sh
```

**确认：** 云上 `curl -s 127.0.0.1:8832/v1/health` 变成 `"phone_connected": true`。手机 Chrome 打开 `http://127.0.0.1:8190/` 能看见眼睛。

**把脸页装成"应用"：** Chrome 打开 `http://127.0.0.1:8190/` → 菜单 → 添加到主屏幕 → 安装。装成应用以后才是真全屏（见[踩坑](踩坑.md)第 1 条）。折叠屏要在系统设置里把 Chrome 单独勾进"合盖继续使用"（第 2 条）。

**让手机能自己把脸拉回前台（可选）：** `start-face.py` 要用你手机上这张快捷方式的原始启动参数。`~/phone-agent/rish -c 'dumpsys shortcut'`，找到 `webapp_url` 是 `http://127.0.0.1:8190/` 的那一张 Chrome 快捷方式，把它启动参数里的每一项原样存成 `~/phone-agent/pwa-shortcut.json`（一个 JSON 对象，键是参数名，值是字符串，图标和签名那几项一个字都别改）。没有这个文件，脸页被切走以后不会自动回来，其他都照常。

**开机自启：**

```
mkdir -p ~/.termux/boot
ln -sf ~/phone-agent/boot-entry.sh ~/.termux/boot/start
```

## 3. 手机：别让系统把它关掉

国产系统会冻结、杀后台。我们一层一层都开了（自启动、省电无限制、最近任务加锁、电池白名单），还是会掉，最后靠的是"被关掉以后自己恢复"。做法、装法、怎么验，全在 [keepalive/README.md](../keepalive/README.md)。先读[踩坑](踩坑.md)第 7 到 13 条。

## 4. AI 那头

**让手机做事：** [`ai-side/phone.py`](../code/ai-side/phone.py)

```
python3 ai-side/phone.py say "我看见你了"
python3 ai-side/phone.py state 在干活
python3 ai-side/phone.py do tap_text '{"text":"设置"}'
```

AI 跟中转不在同一台机器上的话，用 `ssh -L 8832:127.0.0.1:8832 云上那台` 把端口带过来，再设 `RELAY_URL`。

**让 AI 知道手机上发生了什么：** [`ai-side/events.py`](../code/ai-side/events.py) 常驻，把"被戳了两下""回来了""打字留言""太烫了"攒成一句，用 tmux 敲进 AI 的会话。

```
TMUX_TARGET=ai:0.0 python3 ai-side/events.py
```

**看图（可选）：** [`server/body_vision.py`](../code/server/body_vision.py) 常驻在云上。它隔一阵向手机要一帧画面，过几道门（画面变没变、每分钟每小时的上限、敏感词、该不该开口的打分），值得说的才把一句描述敲进 AI 的会话。

```
echo '你的 OpenRouter 钥匙' > .private/openrouter-api-key
cp deploy/vision.example.json deploy/vision.json     # tmux_target 填 AI 会话所在的 tmux 窗格
python3 -B server/body_vision.py --config deploy/vision.json check   # 只检查配置，不花钱
sh deploy/run-vision.sh                                              # 常驻；cron 每分钟拉一次也行
python3 -B server/body_vision.py --config deploy/vision.json notebook  # 看它最近记了什么
```

想让它分得清画面里是不是本人，放一张本人的照片到 `.private/vision/owner-ref.jpg`。

**跟 AI 说清楚规矩。** 在 AI 的长期说明里写上：以 `[手机 …]` 开头的消息是手机报的事，不是人在聊天；回话用 `phone.py say`；人在上班、开着静音或全关的时候别出声。

## 5. 打电话（可选）

网页电话的手机端在 [`call-web/`](../code/call-web)。它要接一个**语音网关**：网关一头连着电话，一头连着 AI 的会话，把人说的话交给 AI、把 AI 的回话合成声音送回来。我们的网关跟我们自己的 AI 会话绑在一起，拆不出来，没放进这个仓库。它要说的协议写在 [电话网关.md](电话网关.md)，照着做一个就能接上。

```
cp ~/call-web/config.example.json ~/call-web/config.json
```

改 `gateway`（网关地址）、`device_token_file`（网关的设备口令文件）、`whisper_binary` 和 `whisper_model`（手机本地的 whisper.cpp，云听写不通时兜底用。我们是在 Termux 里把 whisper.cpp 原生编出来，配中文能用的 tiny 模型；准确度一般，只当退路）。`termux-boot.sh` 看到 `~/call-web/start.sh` 就会一起拉起来。

**确认：** 在脸上往上划，会开始拨号。

## 6. 远程换代码（可选）

改了手机上的代码，不用每次插线。在云上：

```
python3 server/update_phone.py 版本名 phone-agent/agent.py face/face.js ...   # 打包、上传、让手机装
python3 server/update_phone.py --status                                    # 看手机现在是哪一版
```

在别的机器上打包的话，先 `ssh -L 8832:127.0.0.1:8832 云上那台`，再加 `--upload` 把包传上去。

手机收到包先校验每个文件的 sha256，再整体换上；装完读不回来、或者起不来，自动退回上一版。`config.json`、口令、`pwa-shortcut.json` 这些不在包里，换版本不会动它们。
