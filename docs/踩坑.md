# 踩坑

按撞上的先后排。原因没查清的，照实写没查清。

## 1. 网页装不成"应用"，只是个浏览器快捷方式

- **现象**：把脸页"添加到主屏幕"，打开还是带地址栏的普通浏览器。
- **原因**：网页的 manifest 里没有图标。Chrome 只在 192 和 512 两种图标都齐的时候才把它装成真正的网络应用。
- **怎么过的**：补齐图标。装成网络应用以后，合盖外屏上是真正的全屏，没有地址栏、状态栏、导航栏。

## 2. 合上盖，脸就回到桌面了

- **原因**：系统里"合盖继续使用"的总开关开着，但 Chrome 这一项单独是关的。
- **怎么过的**：设置 → 外屏 → 合盖显示，把 Chrome 单独勾上。

## 3. 展开和合上用的不是同一个摄像头

- **现象**：合盖时镜头对着人，展开后拍的是桌子。
- **怎么过的**：按当前屏幕的长宽比判断是内屏还是外屏，内屏用前置、外屏用后置（后置和外屏在同一面），屏幕尺寸一变就重开摄像头。

## 4. 本地检测人的模型在 Worker 里加载不了

- **现象**：MediaPipe 在 module Worker 里 `importScripts` 失败。
- **怎么过的**：改成 classic Worker 加动态 import。模型和 WASM 都放在手机本机，不走网络。

## 5. Shizuku 一次只吐 4096 字节

- **现象**：经 Shizuku 的 rish 读屏幕内容、截图，输出被截断。
- **怎么过的**：让命令把结果写到 Termux 自己的目录里的一个文件，程序直接读文件。截图在手机本地先缩小再传。

## 6. 远程截图截的总是内屏

- **原因**：截图命令固定截了第一块屏。
- **怎么过的**：先读当前是合盖还是展开，再选对应的那块屏。

## 7. 进程还在，但是不动了

- **现象**：手机上常驻的 Python 进程都活着，pid 没变，但云上显示手机掉线。
- **原因**：小米系统会把后台应用"冻结"。进程停在 `do_freezer_trap`，没死，也不跑。
- **怎么过的**：系统有一个免冻结的应用名单（一个非公开的系统设置项），把 Termux 加进去。先存原值，只在原来的列表里追加，不覆盖。
- **后来**：一个月后发现名单里的 Termux 没了，值回到了改之前的样子。怎么没的没查清。所以掉了的时候，先读这个设置项。

## 8. 重启以后什么都没起来

- **现象**：重启手机，开机脚本根本没跑。
- **原因**：读系统记录，Termux:Boot 的"自启动"是被拒绝的，拒绝的时间正好是开机那一刻。这一项当初明明开过。什么时候、怎么关掉的，没查清。
- **怎么过的**：重新放开。同时不再只靠开机自启，加了定时任务那一层（见 keepalive）。

## 9. Shizuku 重启后要重新配对

- **原因**：Shizuku 靠无线调试开机自启，要连着 Wi-Fi。无线调试的配对被清掉过一次（关开过开发者选项之后）。
- **怎么过的**：用线从电脑上起。没有 Wi-Fi 时怎么自己起，还在找。

## 10. 脸页老是自己跳回前台

- **现象**：人想用这部手机聊个天，脸页每隔一会儿把自己拽回最前面。
- **原因**：我们写了一个"镜头断了就把脸页拉回前台"的守护，拉三次，过十分钟再拉三次。它分不清"脸页坏了"和"人自己切走了"。
- **怎么过的**：还没过。先让 AI 闭眼（闭眼时守护不动作）。要做的是悬浮小窗和一个"别拉了"的开关。写在这里，是因为这是自动恢复最容易犯的错：恢复得太积极，抢了人的手机。

## 11. 两天没连上，AI 没发现

- **现象**：手机掉线两天。AI 每次醒来看一眼，都记成"镜头关着，或者人不在"。
- **原因**：取不到画面有很多种原因，AI 把所有情况都当成了最无害的那一种。
- **怎么过的**：先查手机连没连着云，再说人在不在。掉了、人醒着，就告诉人。

## 12. 看图的模型把眼镜说成鼻管

- **现象**：识图报告"鼻子上插着透明的管子"。
- **原因**：透明边框的眼镜。
- **怎么过的**：记下这类认错的对照；拿不准的画面，AI 先取原图自己看，再开口。把连续几帧串起来再判断，不凭一帧说话。

## 13. 猜错了原因

- **现象**：人拔掉数据线几分钟后手机掉线。我们以为是"用线启动的 Shizuku，拔线就死"。
- **实际**：读系统的进程退出记录，Shizuku 一直活着。死的是 Termux，原因写着 `SwipeUpClean`：它的卡片在最近任务里被划走了。
- **教训**：安卓会记下每个应用最近是怎么死的（`dumpsys activity exit-info <包名>`）。先读它。
