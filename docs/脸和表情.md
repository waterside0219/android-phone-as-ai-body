# 脸和表情

脸页有两种样子：一副戴眼镜的松石绿小眼睛（默认，纯 SVG 画的），和一个 Live2D 半身像。设置里能切换；Live2D 闲着 5 分钟会自己退回小眼睛，省电也防烧屏。

代码在 [`code/face/`](../code/face)：`eye-expressions.js` 管眼形和变形，`work-indicator.js` 管打字特效，`eye-outfits.js` 放装扮，`face.js` 管触摸和整页的动画循环。

## 他在干什么：四个状态

AI 用 `python3 ai-side/phone.py state 在想`（或 在干活、在等、卡住了）告诉脸它此刻在干什么。每个状态有一组眼形，12 到 20 秒换一个，看起来不呆：

| 状态 | 轮着出的眼形 |
|---|---|
| 在等 | 平常 |
| 在想 | 往右上看、半眼皮 |
| 在干活 | 往下看、眯眼；下面还会浮出一排看不见的键盘在打字 |
| 卡住了 | X 眼、炸毛（`> <`） |
| 他在说话 | 笑、平常、笑、半眼皮（不管是哪个状态） |

## 一共 13 种眼形

平常、眨眼、半眼皮、笑、爱心、眯眼、惊讶、困、往右上看、往下看、X、炸毛、镜片反光。另外降温的时候是闭着的眼：把笑眼那道弧上下翻过来，像睡着了。

**怎么变过去的：** 每种眼形的轮廓，一开始等距取 96 个点。换表情时每一帧把这 96 个点从当前的位置往目标挪，650 毫秒，两头慢中间快。换到一半又要换，就从当下的样子接着变，不会跳回去重来，也不是两张图淡入淡出。眼镜框跟着动：笑和爱心往上抬一点，半眼皮和困往下沉，再带一两度的歪。眨眼只压眼睛，镜框不动。

## 摸他

| 你做什么 | 他怎么样 |
|---|---|
| 点一下 | 眼睛看向你点的地方，变成爱心眼，2.6 秒 |
| 连点两下 | 马上拍一张给 AI 看 |
| 按住（超过 0.35 秒） | 爱心眼，松手 1.8 秒后回去 |
| 在下半屏横着蹭 | 挠下巴：爱心眼，2.4 秒 |
| 按住 3 秒 | 闭眼；再按 3 秒睁开 |
| 两根手指按住 2 秒 | 锁住触摸；再来一次解开 |
| Live2D 模式下摸耳朵 | 耳朵抖一下 |

点、挠下巴、按住，都会作为事件告诉 AI（[`ai-side/events.py`](../code/ai-side/events.py) 会把它们攒成"戳了你 2 下、挠你下巴"这样一句）。正在打电话的时候，这些手势都让给电话。

## 干活时的打字特效

状态是"在干活"的时候，脸下面浮出一排看不见的键盘：三排字母加一个空格键，像隔着桌子看对面的人打字，空格在他那一侧，字母排靠近你。

键是一个一个亮的，顺序照着一句真的话（`the quick brown fox`）在键盘上的位置走：字母之间隔 95 到 180 毫秒不等，词和词之间停 0.34 秒，一句打完歇 1.7 秒再从头来。每个键按下去先亮到半透明（0.5），往下沉一点，0.14 秒后开始暗，留一点余光，1.5 秒内灭干净。头和眼睛跟着打字的节奏轻轻点。

闭眼、全关、降温、页面在后台的时候，不出键盘。

## 自己加表情

都在 `code/face/eye-expressions.js`：

- `shapes`：每种眼形的轮廓，SVG 的 path，坐标以眼睛中心为原点。
- `presets`：每个表情用哪个眼形、镜框怎么摆，`frame: [左右, 上下, 角度]`。
- `sequences`：每个状态轮哪几个表情。

加一个新表情：在 `shapes` 里写轮廓，在 `presets` 里登记，再放进某个状态的 `sequences`。变形不用另写，96 个点会自己算。

## 装扮

设置里"装扮"那一行。`code/face/eye-outfits.js` 只放数据，每条是：

```js
{ id: 'xxx', label: '名字', color: '#ff8c1e',            // 只换颜色，写到这里就够了
  atlas: { src: 'xxx-atlas.jpg', width, height },          // 要换造型就给一张贴图
  variants: { ... }, expressions: { 日常的表情: 这套里对应的造型 } }
```

只换颜色的装扮加一条就行，设置里会自动多一个选项。要换造型，给一张贴图，把每种眼形对到贴图上的位置；帽子、小配件放在镜框那一层，会跟着镜框一起抬、歪、漂移。我们自己做过一套万圣节（南瓜眼、歪帽子、小蝙蝠），贴图没放进仓库。选了哪套装扮存在浏览器里，刷新、更新以后还在；不看日期，不会自己换。

## 一直亮着的屏幕

外屏是 OLED，脸整天亮着，所以整张脸隔 2 到 4 分钟挪开几个像素、下一回再挪回中间；没人 10 分钟调到两成亮，30 分钟整张脸熄掉，人一回来马上亮回去。机身到 42℃ 就闭眼停镜头。细节在[踩坑](踩坑.md)第 14、15 条。
